추천순 : utils/rankingCalculator.js에 있음
100점 만점(판매40:평점25:리뷰15:최신성10:할인율10)

판매량(40): 100개가 만점, 로그스케일
1개:  0.301 / 2.0043 * 40 = 6.01 점
10개: 1.041 / 2.0043 * 40 = 20.78 점
20개: 1.322 / 2.0043 * 40 = 26.39 점
40개: 1.613 / 2.0043 * 40 = 32.19 점
60개: 1.785 / 2.0043 * 40 = 35.63 점
100개:2.004 / 2.0043 * 40 = 40.00 점

평점(25): 기존 평점이 0~5.0이므로 그냥 평점 * 5

최신성(10): 등록일(createdAt) 기준 30일이내면 점수 추가
예시:
(30 - 지난 일수 / 30) * 10
어제 올라온거: (30 - 1 / 30) * 10 = 29/30 * 10 = 9.66..점
15일 전에 올라온거: (30 - 15 / 30) * 10 = 1/2 * 10 = 5점

할인율(10):
최대 할인율(99%) 대비 할인율(할인 없으면 0)
예시:
할인율20%: ( 0.2 / 0.99 ) * 10 = 2.02...점
할인율50%: ( 0.5 / 0.99 ) * 10 = 4.95점
할인율90%: ( 0.9 / 0.99 ) * 10 = 9.09...점

리뷰수(15): 0~3개(과제 요구사항)
로그스케일로 구현 - 리뷰 0개랑 1개의 차이는 크지만 1개에서 2개 / 2개에서 3개는 상대적으로 크지 않음
리뷰 0개: 0점
리뷰1개: (log10(2) / log10(4)) * 15 = 7.5점
리뷰2개: (log10(3) / log10(4)) * 15 = 11.88...점
리뷰3개: (log10(4) / log10(4)) * 15 = 15점

제품(Product) 스키마 속성
  _id: {	// id는 알아서 1부터 1씩 증가됨
    type: Number
  },
  name: {
    // 상품명. 앞뒤 공백 알아서 제거함(검색 편의 위해)
    type: String / Not Null
  },
  description: {
    // 상품 설명
    type: String / Not Null
  },
  originalPrice: {
    // 원가(정가)
    type: Number / Not Null
  },
  discountRate: {
    // 할인율 (0~1.0) 기본값: 0
    type: Number
  },
  createdAt: {
    // 상품 등록일(생성일) - 기본값: 현재 시간
    type: Date
  },
    soldCount: {
    // 총 판매량 (주문 시 증가) - 기본값: 0
    type: Number
  },

  // 할인 기간(discountRate가 존재하면 사용)
  saleStartDate: {
    type: Date,
  },
  saleEndDate: {
    type: Date,
  },

  // 리뷰 통계(평균 평점 계산용) - 기본값: 둘다 0
  reviewCount: {
    type: Number
  },
  totalRatingSum: {
    type: Number
  },

  // 이미지 목록 - 이미지 스키마 가져옴
  images: [ImageSchema],

  // 사이즈 - 숫자 배열 형태
  sizes: [Number],  // 예: [240, 245, 250]

  // 소재 - String 배열 형태
  materials: [String],  // 예: ["가볍고 시원한 tree", "면"]
  
  // 카테고리 (중복 선택 가능) - String 배열 형태
  // 예: ["라이프스타일"], ["슬립온"], ["라이프스타일", "슬립온"]
  categories: [String],
  
  // 리뷰 목록 - 리뷰 스키마 가져옴
  reviews: [ReviewSchema]
